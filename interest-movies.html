04 / AURORA CINEMA

电影结束以后，
总有一句话留下。

欢迎进入一场私人放映。横向滑动票根，选择今晚想看的主题；银幕每次只亮起一组故事。

时间选择真实记忆
TONIGHT'S PROGRAM / 05
FEATURE 01 / TIME AND DISTANCE

越过漫长时间与遥远星际，仍要继续向前。

有些电影把人送往宇宙深处，有些只让一个普通人在自己的道路上不停奔跑，还有一些把宏大的答案放回一餐一饭。面对未知，重要的是仍愿意出发，仍认真生活。

《星际穿越》“不要温顺地走进那个良夜。”
《阿甘正传》“生活就像一盒巧克力，你永远不知道下一颗是什么味道。”
《欢迎来龙餐馆》“没有什么比好好吃饭、好好培养下一代更重要的事了。”
FEATURE 02 / CHOOSING ONESELF

看清选择的代价，然后决定自己要成为谁。

成长并不只是获得更多，也意味着辨认什么值得留下、什么必须放下。有人在职业与野心中重新看见自己，有人站上课桌寻找新角度，也有人宁愿留在有限的琴键之间。

《穿普拉达的女王》“清醒的人，忠于自己。”
《死亡诗社》“自由、诗歌、美丽、浪漫、爱——这才是我们活着的意义。”
《海上钢琴师》“我不是下船，我是离开此生。毕竟，我不为任何人存在。”
FEATURE 03 / INVISIBLE CAGES

最难逃离的牢笼，往往披着爱与真实的外衣。

银幕上的牢笼不一定有铁栏。它可能是一场被设计好的人生，也可能是一段以爱为名不断收紧边界的关系。

《楚门的世界》“世界是一场骗局，人生是一个秀场；真的我，活在你的瞳孔里。”
《消失的她》“为何爱我者予我牢笼，为何囚人者也像困兽。”
FEATURE 04 / MEMORY AND HUMANITY

记忆让爱穿过告别，人性让生命不只是数字。

有些电影谈论死亡，却真正关心一个人如何被记住；有些凝视历史最黑暗的时刻，让每一次拯救重新拥有具体的重量。

《寻梦环游记》“死亡不是终点，遗忘才是。”
《辛德勒的名单》“当你挽救一条生命，就等于挽救了全世界。”
《给阿嫲的情书》“江海万里，心中念你，便不觉遥远。”
AFTER THE CREDITS / WHAT I KEEP

我收藏的不是答案，而是被触动过的证据。

我不会要求每部电影都告诉我一个道理。有些故事只需要在某个时刻与我相遇，让我短暂地理解另一种处境，或者重新看见自己已经习惯的生活。

“银幕暗下去以后，感受仍然可以继续生长。”
