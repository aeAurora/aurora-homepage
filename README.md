# Aurora 个人主页 · 项目目录

赵昕瑶（Aurora）的《Project-Based CST&AI Foundations》课程作业项目。
把主页代码、虚拟形象设定、课程过程记录集中在**这一个文件夹**里，不再散落在工作区根目录。

## 目录结构

```
aurora-homepage\
├─ index.html                  ← 个人主页（含 ae果 对话挂件），双击即可打开
├─ test-match.js               ← 挂件问答自测脚本（改完问答库后可复跑）
├─ README.md                   ← 本文件
└─ docs\
    ├─ 形象卡.md                ← 虚拟形象六层设定（给人看）
    ├─ 系统提示词.md            ← 可直接贴进代码的提示词（给机器用）
    ├─ 本地问答库.md            ← 离线版问答数据：A 28 条能答 / B 8 条拦截 / C 1 条兜底
    └─ process-log.md           ← 课程过程记录：需求、AI 使用、测试、四周计划
```

> `旧版-勿用_*.txt` 是历史快照，**不要读、不要用**。所有文档以本目录下的 `.md` 为准。

## 怎么用

- **看主页**：双击 `index.html`，用浏览器打开。右下角点「果」就能和 ae果 对话（本地运行，不需要联网）。
- **看设定**：`docs\形象卡.md`
- **改问答**：改 `docs\本地问答库.md`，然后让 AI 把 A / B 两部分转成 JS 数组写进 `index.html`。
- **自测**：改完在 `index.html` 所在文件夹执行 `node test-match.js`。它会从 `index.html` 里真实读出问答数据，跑 10 条边界用例，并检查回答里有没有泄露出生日期。最后一行打印「通过」才算没问题。
- **接真 AI**：以后如果给挂件接真实 AI 接口，把 `docs\系统提示词.md` 横线之后的内容整段贴进系统提示即可。
